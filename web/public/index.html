02 / Four Chameleon functions

One pill. Four instincts.

TapCopy reads what you selected and shows only the segments that make sense. No shortcuts to memorize, no window stealing your focus.

CopyRGB
Copy= 500
Copy↗ Open

Smart detection

Links get Open. Real file paths get Show in Finder. #10B981 turns into rgb(16, 185, 129) with a live swatch. (49 * 12) - 88 resolves to = 500 on the spot.

Dates and phone numbers are ignored: 2026-11-14 is never treated as a subtraction.

launch_checklist

Plain text + Aa

Plain copies clean text without formatting. Aa converts to UPPERCASE, lowercase, Title Case, snake_case, camelCase or a Markdown code block, with a live word and character count.

⌕GoogleGitHubStack Overflow

1-click search

The magnifier searches the web instantly. When the selection looks like code, the menu adds GitHub code search and Stack Overflow.

Floating Pin Shelf

Pin up to 4 draggable cards on screen, Dropover-style. Copy them again later and close them when you're done. The fifth pin replaces the oldest.

✦ AI 123 456

Zero-overlap engine

TapCopy reads the macOS Accessibility tree and floating windows before it appears, so it never covers web buttons like “Ask Gemini”, Notion bars, Medium or ChatGPT toolbars. Six candidate slots are scored every time.

No Screen Recording permission required.

0.0% CPU

Featherweight & native

Swift 5.10 and pure AppKit. Under 1 MB, 0.0% CPU at rest, built for macOS 14 Sonoma or later. Selecting text never writes to your clipboard.

04 / Tutorial

From install to your first pill.

Watch the walkthrough: Accessibility permission, Chameleon Mode and the Pin Shelf.

  1. 01

    Install and open

    TapCopy lives in your menu bar. Drag it from the .dmg to Applications and open it.

  2. 02

    Grant Accessibility

    System Settings → Privacy & Security → Accessibility. The menu-bar icon switches from a warning triangle to the clipboard silhouette.

  3. 03

    Select and click

    Drag over text, double-click a word or Shift-click to extend. Click a segment. The pill hides after 5 seconds, or instantly with Esc.
